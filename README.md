# La Bagelerie Website

Crée un site web one-page pour un restaurant de bagels artisanaux nommé "La Bagelerie", 
situé à Étrépagny en Normandie.

INFORMATIONS DU RESTAURANT :
- Nom : La Bagelerie
- Type : Restaurant/snack spécialisé bagels
- Adresse : 26 Rue du Maréchal Foch, 27150 Étrépagny
- Téléphone : 02 32 15 39 31
- Note : 4,8/5 (117 avis)
- Gamme de prix : 10–20 € par personne
- Services : repas sur place, vente à emporter, livraison
- Instagram : @labageleriedecamillebymarie

STYLE VISUEL :
- Ambiance chaleureuse et artisanale, esprit "café-bakery" moderne
- Palette de couleurs : tons chauds (crème, moutarde, brun caramel, touches de vert sauge ou terracotta)
- Typographie : une police display légèrement rétro/manuscrite pour les titres (esprit fait-main), 
  une sans-serif propre pour le texte
- Photos généreuses de bagels, produits frais, intérieur cosy
- Design responsive, mobile-first (beaucoup de clients chercheront l'adresse/horaires depuis leur téléphone)

STRUCTURE DE LA PAGE :
1. Header : logo/nom, navigation (Menu, À propos, Avis, Contact), bouton "Commander" ou "Nous appeler" visible
2. Hero : grand visuel de bagel, accroche courte, CTA (voir le menu / itinéraire)
3. Section "Notre histoire" : présentation courte et chaleureuse du concept artisanal
4. Section Menu : présentation des bagels/formules avec photos, prix indicatif (10–20 €), 
   catégories (salés, sucrés, boissons, formules midi)
5. Section Avis clients : mettre en avant la note 4,8/5 et quelques avis clients (à insérer)
6. Section Services : pictos clairs pour repas sur place / à emporter / livraison
7. Section Contact/Localisation : adresse complète, téléphone cliquable, carte intégrée (Google Maps), 
   horaires d'ouverture (jour par jour), lien Instagram
8. Footer : coordonnées, réseaux sociaux, mentions légales

FONCTIONNALITÉS :
- Bouton cliquable "Appeler" (lien tel:)
- Bouton "Itinéraire" qui ouvre Google Maps avec l'adresse
- Intégration du flux Instagram ou au moins un lien stylisé vers le compte
- Formulaire de contact simple (nom, email, message) ou lien direct vers réservation si besoin

TON DU CONTENU :
Convivial, gourmand, proche du client — mettre en avant le côté fait-maison et artisanal 
plutôt qu'un discours trop corporate.
